# ✅ TodoApp

### Flutter To-Do List Application

**TodoApp** adalah aplikasi mobile sederhana berbasis **Flutter** yang digunakan untuk mencatat dan mengelola daftar kegiatan (to-do list).  
Aplikasi ini menampilkan form input tugas, validasi data, pemilihan tanggal dan jam, serta fitur checklist untuk menandai tugas yang sudah selesai.

Project ini dibuat sebagai latihan pengembangan aplikasi mobile menggunakan **Flutter** dan **Dart**, dengan fokus pada form, validasi input, pengelolaan data, dan interaksi antarmuka.

---

## ✨ Fitur Utama

- Menambahkan data tugas melalui form
- Validasi input ketika data belum lengkap
- Memilih tanggal dan jam tugas
- Menampilkan data yang berhasil ditambahkan
- Checklist untuk menandai status tugas
- Perubahan tampilan ketika tugas sudah dicentang
